# Git

## Repository

Репозиторий — это проект, за которым мы следим в Git и храним информацию

## Commit

Commit — это сохраненная точка состояния проекта

## Branch

Branch — это отдельная линия разработки внутри репозитория

## Merge

Merge — слияние веток внутри проекта

## Rebase

Rebase — переносит коммиты на новую ветку, переписывая историю

## Tag

Tag — это создание ярлыка на конкретном коммите

## Remote Repository

Remote repository — ...

## Clone

Clone — это клонирование проекта из гитхаба 

## Fetch 

Fetch — это скачать изменения в проекте от другого разработчика, узнав эти изменения

## Pull

Pull — это скачать и применить изменения относительно файлов к текущей ветке

## Revert

Revert — это отмена изменений в коммите, созданием нового коммите об отмене

## Restore

Restore — удаляет изменение из рабочей зоны

## Reset

Reset — выполняет перемещение ветки/головной и может вносить изменения в промежуточной зоне

## Cherry-Pick

Cherry-Pick — это перенос коммита из одной ветки в другую без слияния веток
